Task 15 - JavaScript Array Operations
📌 Overview

This project demonstrates the use of different types of JavaScript functions to perform common array operations. A dummy array is used to test each function, and the results are displayed in the console.

🚀 Features
Find the maximum number in an array.
Calculate the sum of all array elements.
Count the number of odd elements in an array.
Use different types of JavaScript functions:
Arrow Function
Anonymous Function
Regular Function
Display results using console.log().
🛠️ Technologies Used
HTML
JavaScript (ES6)

📋 Function Details
1. Find Maximum Number

Uses an Arrow Function to find the largest element in the array.

2. Calculate Sum

Uses an Anonymous Function to calculate the total sum of all array elements.

3. Count Odd Numbers

Uses a Regular Function to count the number of odd values present in the array.

💻 Sample Array
let arr = [12, 7, 25, 18, 9, 31, 4];
📊 Sample Output
Array: [12, 7, 25, 18, 9, 31, 4]
Maximum Number: 31
Sum of Elements: 106
Number of Odd Elements: 4
▶️ How to Run
Clone or download the project.
Open the project folder.
Open index.html in a web browser.
Open the browser's Developer Tools (F12).
Navigate to the Console tab.
View the output of all array operations.
